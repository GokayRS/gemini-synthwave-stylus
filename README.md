# Gemini Synthwave 🌆✨

[English](#english) | [Español](#español)

---

## English

Custom dark theme for the Google Gemini web interface via Stylus. Designed with a **Toxic Violet** & **Cyberpunk Synthwave** aesthetic, high-contrast neon highlights, and a clean full-width responsive layout.

### 🌟 Key Features
- **Full-Width Layout:** Maximizes prompt and response space across widescreen monitors.
- **Synthwave Palette:** Deep `#0c0814` background paired with `#3D007A` borders and `#E8ECF1` Soft Chrome readable text.
- **Neon Typography:** Electric Cyan headers (`#00F0FF`), Bright Mint bold highlights (`#00ff9d`), and Magenta accents (`#ff007f`).
- **Clutter Free:** Hides footer disclaimers, upsells, and unnecessary horizontal borders.

### 🚀 Installation

1. Install the **Stylus** extension for your browser ([Chrome](https://chrome.google.com/webstore/detail/stylus/clbfbmidbdobicbbnoobnhmoaikkdbec) / [Firefox](https://addons.mozilla.org/en-US/firefox/addon/styl-us/)).
2. Click the link below to install the style directly:
   👉 **[Install Gemini Synthwave](https://raw.githubusercontent.com/GokayRS/gemini-synthwave-stylus/main/gemini-synthwave.user.css)** *(Raw File)*
3. Stylus will open. Click **"Install Style"**.

## Español

Tema oscuro personalizado para la interfaz web de Google Gemini a través de Stylus. Diseñado con una estética **Toxic Violet** y **Synthwave/Cyberpunk**, resaltados neón de alto contraste y un diseño panorámico que aprovecha todo el ancho de la pantalla.

### 🌟 Características Principales
- **Diseño Ancho Completo:** Elimina los márgenes estrechos y aprovecha todo el espacio en monitores panorámicos.
- **Paleta Synthwave:** Fondo noche profundo `#0c0814`, bordes `#3D007A` y texto de lectura descansado `#E8ECF1` (Soft Chrome).
- **Tipografía Neón:** Encabezados en cian eléctrico (`#00F0FF`), negritas en menta brillante (`#00ff9d`) y acentos en magenta (`#ff007f`).
- **Interfaz Limpia:** Oculta avisos del pie de página, promociones de suscripción y líneas divisoras molestas.

### 🚀 Instalación

1. Instala la extensión **Stylus** en tu navegador ([Chrome](https://chrome.google.com/webstore/detail/stylus/clbfbmidbdobicbbnoobnhmoaikkdbec) / [Firefox](https://addons.mozilla.org/es/firefox/addon/styl-us/)).
2. Haz clic en el siguiente enlace para instalar el tema directamente:
   👉 **[Instalar Gemini Synthwave](https://raw.githubusercontent.com/GokayRS/gemini-synthwave-stylus/main/gemini-synthwave.user.css)** *(Archivo Raw)*
3. Se abrirá Stylus automáticamente. Pulsa en **"Instalar estilo"**.
